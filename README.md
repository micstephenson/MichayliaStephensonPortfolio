# 🦋 Michaylia Stephenson — Portfolio

A playful, interactive software engineering portfolio built with **React**, **GSAP**, and **Vite**.

🌐 **Live site:** https://michayliastephenson.com  
💻 **Repository:** https://github.com/micstephenson/MichayliaStephensonPortfolio

## ✨ About

This portfolio showcases my software engineering experience, projects, skills and interests through a highly visual and interactive website. It combines a playful butterfly theme with editorial typography, animated page transitions and scroll-based GSAP interactions.

## 🛠️ Tech Stack

- **React 19** — component-based frontend
- **JavaScript / JSX**
- **GSAP 3** — animations and interactions
- **GSAP ScrollTrigger** — scroll-driven animation
- **Tailwind CSS 4**
- **CSS3**
- **Vite** — development and production builds
- **ESLint** — code quality
- **React Responsive** — responsive layouts

## 🦋 Features

- Custom animated loading/landing page
- Interactive navigation
- GSAP scroll-driven animations
- Horizontally scrolling project showcase
- Individual project detail pages
- Individual experience detail pages
- Animated swipe/split page transitions
- Flying decorative butterflies
- Butterfly scroll indicator
- Responsive layouts for different screen sizes
- Downloadable CV
- Custom pink, cream and butterfly-themed visual identity

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- Git

### Clone the repository

```bash
git clone https://github.com/micstephenson/MichayliaStephensonPortfolio.git
cd MichayliaStephensonPortfolio
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Vite will normally make the site available at `http://localhost:5173`.

### Production build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```
